# Kivou
<!-- impeccable:product-schema 1 -->
## Platform
Windows x64 Electron desktop, English interface; multilingual user inputs and outputs.
## Product and audience
Open-source creator assistant for independent creators and freelancers. A licensed distribution of Goose v1.56.0, upstream commit 9949cf926cd42f1d128b9991ed23a496ecace896. Three workflows: source-aware Research Brief, Content Pack, and deterministic Asset Manifest. Each run produces local Markdown, JSON and state records for human review.
## Confirmed choices
User chose an improved open-source fork, Windows first, English global presentation, short professional name Kivou, public repository rayaneDR/kivou, plus an English Remotion motion-graphics ad from actual interface captures. No repeated visual interview is needed: the user explicitly instructed proceeding on this approved plan.
## Constraints
Zero additional spend. One model run at a time on an approximately 8 GB RAM PC. Existing Codex authentication via ACP, no paid fallback, no automatic import of user plugins. No automatic posting or sending. Original asset folders are read-only. Local per-run exports never overwrite. Credentials and personal data are not bundled or published.
## Success
A new Windows user can launch, check model connection, complete a workflow, inspect sources and review flags, reopen saved results and export a separate delivery folder. Real-model and deterministic test evidence must be distinguished. No stars, revenue or ranking guarantees.
